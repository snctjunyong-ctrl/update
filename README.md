# HyperSuperCat

An utterly unhelpful alien cat for your Mac.

This repository hosts app releases only. Application source code is not published here.

## Download

[Latest release](https://github.com/snctjunyong-ctrl/update/releases/latest)

Download `HyperSuperCat-Mac.zip`, unzip it, and move HyperSuperCat.app to Applications. Requires macOS 14 or later and Apple Silicon.

Use the green alien cat in the menu bar to change settings, choose a language, check for updates, or quit.

## Updates

The app checks this repository for a newer published release at most once a day. You can disable automatic checks or check manually. Downloading and replacing the app is manual; it does not install updates automatically.

Supported languages: English, 한국어, 日本語, 简体中文, 繁體中文, Español, Français, Deutsch.
